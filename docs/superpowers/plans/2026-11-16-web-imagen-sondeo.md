# Web: imagen propia en el enlace de un sondeo — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A link to a poll shows an image with that poll's figures: a 1200×675 PNG the server draws on request, declared as `og:image` by the poll page.

**Architecture:** `mtpy/lib/pages/sondeos.py` composes what the image says as plain data (a "preview": title, subtitle, up to six rows, footnote, alt text, version) with the functions the poll page already uses; `mtpy/lib/pages/images.py` draws a preview with Pillow, with the fonts the site serves (the variable woff2, which the FreeType of the Pillow wheels reads) and a wordmark PNG generated once by `web/brand/build.py`; the `Sondeos` controller serves it at the URL of the page plus `.png` and passes it to the page as `og_image`.

**Tech Stack:** Pillow 10.3 (already in `requirements.txt`; its wheels for macOS and for Linux x86_64 and aarch64 bundle FreeType with brotli, checked on 2026-11-16), Jinja2, pytest. `fonttools` + `brotli` only in `web/brand` tooling, as today. No new dependency, no change to nginx nor to the Docker image.

**Spec:** `docs/superpowers/specs/2026-11-16-web-imagen-sondeo-design.md`

## Global Constraints

- PEP8, lines ≤ 120, numpydoc docstring on every function; identifiers and comments in neutral English, public texts in Spanish («sólo» with tilde, «encuestadora/casa», never «empresa»).
- Web code lives inside `mtpy`; `web/brand/build.py` is never imported by the web. Tests never touch the RDS, the network nor `backtest/results`.
- Luis commits in parallel in the same tree: before each commit `git status` and `git log -1`, add only the files of the task, never `git commit -a`. Commit messages in Spanish, in the style of the log, ending with `Co-Authored-By: Claude Fable 5.2 <noreply@anthropic.com>`. No push.
- The figures, names, change and order of the image are the ones of the poll page: `vote_rows`, `previous_poll`, `poll_title`, `seats_text`, `fmt_pct`, `fmt_num`, `sample_text`. Shares with the sign attached («31,9%»).
- Up to **six** rows: the six parties with most vote, by vote (`vote_rows` order).
- Image: PNG, 1200×675, light background of the site (`#f4f5f8`). Texts drawn with `ImageFont.Layout.BASIC` always (the same on every machine, with or without raqm).
- A whole-suite run on a clean copy closes every task that touches `web/templates` (lesson of the previous step).
- Every task that changes a public text or a template leaves the other pages byte-identical.

## Review Focus

- A house, outlet or party name with characters the fonts lack, an emoji or markup (`<script>`): the image is drawn (a box per missing glyph), nothing raises, and the alt text is escaped in the page. (Task 3, `test_poll_png_survives_odd_inputs`; Task 4, `test_poll_page_declares_its_image`)
- A party without a colour in the catalogue, or with an invalid one: its bar is drawn in a neutral grey. (Task 3, `test_poll_png_draws_the_bars_in_the_party_colours`)
- The widest figures («100,0%» with a change of two digits) next to the widest seats («125–136»): the figures never run into the seats column. (Task 3, `test_figures_never_reach_the_seats_column`)
- Long acronyms («PODEMOS-IU-AV») and a title longer than the room at the minimum size: they shrink, then are cut with «…», and never run under the bars nor the wordmark. (Task 3, `test_fit_text_shrinks_then_cuts`)
- The image asked with `mode`, a `run` that does not exist or any other query: the same image of the latest run, never a 400. (Task 4, `test_poll_image_ignores_the_query`)

### Task 2: what the image says, as data

**Files:**
- Modify: `mtpy/lib/pages/sondeos.py`, `mtpy/lib/pages/__init__.py` (exports)

**Interfaces:**
- Produces, in `mtpy.lib.pages.sondeos` (re-exported from `pages`):
  - `PREVIEW_ROWS = 6`, `PREVIEW_DESIGN = 1` (bumped when the drawing changes, so the version changes).
  - `fieldwork_compact(poll: dict) -> Optional[str]` — `'3–5 nov 2026'`, `'29 oct–2 nov 2026'`, `'28 dic 2025–2 ene 2026'`, one date when both coincide or only one is known, `None` without any.
  - `preview_of(poll: dict, previous: Optional[dict], parties: list, colors: dict, election: str, host: str) -> dict` with keys:
    - `title` — `poll_title(poll)`.
    - `subtitle` — `election`, `'Campo: ' + fieldwork_compact` (or the day of the poll, `fmt_date`, without «Campo:», when there are no fieldwork dates) and `sample_text`, joined with `' · '`, each left out when missing.
    - `rows` — the first `PREVIEW_ROWS` of `vote_rows(poll, parties, colors, previous)`, each `{'name', 'color', 'value', 'share' (fmt_pct), 'change', 'seats'}`; `change` is `None` or `{'direction': 'up' | 'down' | 'same', 'text': fmt_num(abs(change), 1) or '='}`; `seats` the text of `vote_rows` or `None`.
    - `has_seats` — whether any shown row has seats.
    - `more` — `None`, `'y 1 partido más en {host}'` or `'y N partidos más en {host}'`.
    - `alt` — `'Sondeo de {title} (campo {fieldwork}): PP 31,9%, PSOE 25,9%.'` with the shown rows (`'({day})'` without fieldwork).
    - `version` — 8 hex characters of the MD5 of `PREVIEW_DESIGN` and everything the image draws (`title`, `subtitle`, `rows`, `more`).
  - `poll_preview(state: dict, date: str, pollster: str, sponsor: Optional[str] = None) -> dict` — the preview of the published poll of that URL (the parts `sondeo_context` reads); `HttpError` 404 `poll not found` as the page.
  - `latest_poll_preview(scope: str, date: str, pollster: str, sponsor: Optional[str] = None) -> Optional[dict]` — the one of the latest run (`parse_state({}, scope)`), `None` when the poll is not there.
  - `sondeo_context` adds `preview` (the one of its own run and data).

- Produces, in `mtpy.lib.pages.images` (used as `pages.images.<name>`):
  - `SIZE = (1200, 675)`, `SCALE = 2` (drawn twice as large and shrunk with Lanczos), the colours `BACKGROUND = '#f4f5f8'`, `INK`, `MUTED`, `FAINT`, `UP = '#16a34a'`, `DOWN = '#dc2626'`, `NEUTRAL = '#9298ac'`, and the layout the tests read: `MARGIN = 64`, `ROW_TOP = 196`, `ROW_STEP = 66`, `BAR_LEFT = 200`, `BAR_MAX = 470`, `BAR_HEIGHT = 40`, `RIGHT = 1136`, `WORDMARK_WIDTH = 200`.
  - `font(name: str, size: int) -> ImageFont.FreeTypeFont` — `name` in `'title'` (Outfit, `wght` 800), `'bold'` (Outfit, `wght` 700), `'body'` (DM Sans, `wght` 500 and `opsz` the size in image pixels, clamped to the axis, as the browser does); the variable woff2 opened with `Layout.BASIC` and pinned with `set_variation_by_axes`; cached.
  - `text_width(name: str, text: str, size: float) -> float` — in image pixels.
  - `fit_text(name: str, text: str, size: float, min_size: float, max_width: float) -> tuple` — `(size, text)`: the largest whole size from `size` down to `min_size` at which the text fits; if none, `min_size` and the text cut to the longest head that fits with `'…'`.
  - `poll_png(preview: dict) -> bytes` — the image of the spec (aspect «A»; sketches in `.superpowers/brainstorm/poll-image/A1…A4`): header (title fitted from 50 to 34 px at the left of the wordmark, subtitle fitted from 25 to 20 px), up to six rows (acronym fitted from 34 to 22 px in its column, bar of `max(8, BAR_MAX * value / largest value)` px in the party colour or `NEUTRAL`, share at 38 px after the bar, change after it: a triangle and the figure in `UP`/`DOWN`, or `=` in `FAINT`), the «Escaños» column right-aligned at `RIGHT` only with `has_seats`, and `more` at the bottom right. Nothing in the bottom-left corner (x < 600, y > 610).

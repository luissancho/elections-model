Hay dos censos. El de la convocatoria es el que el INE cerró el {{ (study_meta.election or {}).get('census_closed')|date }}{% if figures.census_total is not none %} ({{ figures.census_total|int }} electores){% endif %}. {%- if figures.litigation is not none %} El otro resta las {{ figures.litigation|int }} inscripciones en litigio{% if litigation.get('as_of') %} (la cifra al {{ litigation.as_of|date }}{% if litigation.get('source') %}, {{ litigation.source }}{% endif %}){% endif %}: nadie publica dónde están, así que se quitan de las filas latinoamericanas, por provincia en proporción a su crecimiento latinoamericano desde la ley y, dentro de cada provincia, por país.{% endif %}

La brecha es lo que le falta, en votos, al aspirante al último escaño de cada provincia en {{ figures.baseline_year }} para igualar el cociente de quien lo ganó.

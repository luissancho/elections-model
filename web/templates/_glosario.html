{#- Glossary of the error measures (spec "Glosario de medidas de error"): one definition for every page that shows them. Needs `error_blocks` or `blocks` (the first block names the sign of the margin) and `with_herding` and optionally `with_block_error` (default true) (set them before the include: `{% set with_herding = false %}`). `with_errors` (default true) drops the three error measures and `with_rating` (default false) adds the columns of the rating path of a profile; the points rule of «Scoring» reads `quality.per_point` and `quality.floor` (the profile card) and is left out without them. -#} {%- set glossary_blocks = error_blocks if error_blocks is defined and error_blocks else (blocks if blocks is defined else []) %}
Qué mide cada columna
{% if with_rating is defined and with_rating %}
Sondeos
Cuántos sondeos publicó para esa elección de los que entran en el modelo; el error medio, el sesgo del margen y el diferencial son la media de esos sondeos.
{% endif %} {% if with_errors is not defined or with_errors %}
Error medio
Distancia media, en puntos, entre el sondeo y el resultado de cada partido principal. Sin signo.
{% if with_block_error is not defined or with_block_error %}
Error de bloques
Cuánto se equivocó el sondeo en el margen entre los dos bloques principales, en puntos. Sin signo.
{% endif %}
Sesgo del margen
El mismo error con signo: positivo, el sondeo daba más margen {{ 'a ' ~ glossary_blocks[0] if glossary_blocks else 'al primer bloque' }} del que hubo; negativo, menos.
{% endif %} {% if with_rating is defined and with_rating %}
Diferencial
Cuánto se separó el sesgo de sus sondeos del de los sondeos comparables de esa elección (misma fecha y tamaño), en la escala del sesgo del modelo, no en puntos: negativo, menos sesgo que los demás, y eso sube el rating; positivo, más. Un 2 ya es una diferencia grande.
Scoring
Lo que se supone de la encuestadora antes de mirar sus sondeos, de 0 a 100, según una rúbrica pública de cinco criterios sobre cómo trabaja (la calidad previa del método); pesa en el rating mientras tiene pocos sondeos.{% if quality is defined and quality.per_point is defined %} Cada punto vale {{ quality.per_point }} de scoring, con un mínimo de {{ quality.floor }}.{% endif %}
Rating
La nota, de 0 a 100, con la que quedó tras evaluar esa elección con todo su historial anterior, mezclada con su scoring: la que se le aplica hasta la siguiente. La de la primera fila es la de hoy, la que entra en el promedio.
Cambio
Cuánto subió o bajó el rating tras esa elección frente al que tenía al llegar.
{% endif %} {% if with_herding %}
Rebaño
Por debajo de 1, sus sondeos varían menos de lo que permite el azar.
{% endif %}
